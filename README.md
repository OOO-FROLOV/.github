# Профиль FROLOV

Публичное оформление GitHub-организации [OOO-FROLOV](https://github.com/OOO-FROLOV).

- `profile/README.md` — содержимое главной страницы организации.
- `assets/cover.svg` — редактируемая обложка.
- `assets/avatar.svg` — исходник монограммы.
- `assets/avatar.png` — аватар 512 × 512 для загрузки в настройках организации.

README профиля загружается из публичного репозитория `.github`, как описано в [документации GitHub](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile).

Аватар загружается отдельно: настройки организации → Profile → Upload new picture. Изменение файла в этом репозитории само по себе не обновляет аватар организации.
