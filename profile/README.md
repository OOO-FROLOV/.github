### Что делаем

Разрабатываем сайты и веб-системы: от первого экрана до логики, с которой взаимодействует пользователь. Соединяем визуальную часть, понятные сценарии и техническую реализацию.

| Сайты | Веб-системы | Развитие |
| :--- | :--- | :--- |
| Лендинги, сайты услуг и интерактивные портфолио | Личные кабинеты, формы и интеграции | Доработка интерфейсов, контента и возможностей |

### Как работаем

**01 / Разбираемся в задаче** — определяем, для кого продукт и что он должен помочь сделать.

**02 / Проектируем и собираем** — связываем структуру, интерфейс и поведение в работающий сценарий.

**03 / Проверяем и развиваем** — проверяем сборку и пользовательские сценарии, документируем решения и готовим следующие изменения.

### Технологии

**TypeScript · React · Next.js · Node.js · Docker**

CSS Modules и собственные дизайн-токены для интерфейса. Vitest и Playwright для проверки логики и пользовательских сценариев.
